# Evaluación 1 — Planificación

Esta carpeta es la **única** fuente de Eva 1. No uses `Eva 01/` (con espacio) en la raíz del repo: era una copia local y ya no se genera.

## Estructura

- `informe/`: `Informe-Ejecutivo-Eva01.docx` y `Alcance-EDT-y-exclusiones.docx`.
- `informe/insumos/`: pedazos del equipo para armar el Word (no es la entrega).
- `planificacion/`: `Cronograma-Kiran.xml` (Project Libre), Gantt HTML, CSV y `capa-scrum.md` (sprints, roles, eventos).
- `marca/final/`: logo definitivo, variantes y guía de uso. `marca/propuesta/` guarda borradores, no el logo vigente.
- `pitch/`: guion de la presentación a dirección.
- `presentacion/`: deck interactivo HyperFrames, notas del oral y vista previa. El Gantt que abre el deck es copia generada de `planificacion/`.
- `material-oficial/`: rúbrica, caso y PPTs de Duoc. **Solo en tu computador**; Git los ignora.
