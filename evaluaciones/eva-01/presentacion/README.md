# Presentación Eva 01 — Kiran

Deck interactivo de 13 láminas para la defensa oral de GPY1102.

## Abrir para presentar

La versión que se navega es el HTML, como un sitio. Desde esta carpeta:

```powershell
python -m http.server 4173
```

Después abre [http://localhost:4173](http://localhost:4173).

- `→`, `Espacio` o clic a la derecha: avanzar.
- `←` o clic a la izquierda: volver.

HyperFrames es solo el taller para animar y revisar el deck. No hace falta para presentar.

- `index.html`: láminas, diagramas y notas.
- `frame.md`: reglas de la línea gráfica.
- `STORYBOARD.md`: relato completo.
- `preview-presentacion.png`: vista general del deck.
- `gantt-ruta-critica.html`: copia generada de `../planificacion/Gantt-ruta-critica.html` (no editar a mano).
- `assets/`: isotipos, GSAP local, marca Duoc y afiche de cierre. El deck se abre sin internet.

## Estructura del relato

1. Contexto y problema.
2. Propuesta de valor y flujo operativo.
3. Determinación del alcance, EDT y recursos.
4. Ruta crítica y PERT.
5. Enfoque híbrido (Sprint 0, sprints, reserva de capacidad), contexto y estándares.
6. Herramientas, y un cierre que deja la promesa y abre las preguntas.

Esta presentación es navegable; no debe renderizarse como un único MP4.
