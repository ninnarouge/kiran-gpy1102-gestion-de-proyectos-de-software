# Presentación Eva 01 — Kiran

Deck interactivo de 13 láminas para la defensa oral de GPY1102.

## Abrir para presentar

Desde esta carpeta:

```powershell
npm run dev
```

HyperFrames abrirá la presentación en el navegador.

- `→`, `Espacio`: avanzar.
- `←`, `Retroceso`: volver.
- `P`: abrir el modo presentador y la ventana para la audiencia.
- Las notas del oral aparecen solo en la vista del presentador y se pueden editar.

En Google Meet, comparte la pestaña de audiencia. En Zoom, separa esa pestaña
en otra ventana y comparte esa ventana.

## Revisar o editar

```powershell
npm run studio
npm run check
```

- `index.html`: láminas, diagramas y notas.
- `frame.md`: reglas de la línea gráfica.
- `STORYBOARD.md`: relato completo.
- `preview-presentacion.png`: vista general del deck.
- `assets/`: isotipos y copia local de GSAP para presentar sin internet.

## Estructura del relato

1. Contexto y problema.
2. Propuesta de valor y flujo operativo.
3. Determinación del alcance, EDT y recursos.
4. Ruta crítica y PERT.
5. Enfoque híbrido, contexto organizacional y estándares.
6. Herramientas y criterio final de éxito.

Esta presentación es navegable; no debe renderizarse como un único MP4.
