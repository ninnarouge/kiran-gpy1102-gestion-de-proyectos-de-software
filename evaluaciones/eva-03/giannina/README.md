## Cómo abrir las láminas

Abrir `laminas/index.html` en el navegador. Las flechas del teclado cambian de lámina. Las tipografías están en `laminas/assets/fonts`, así que funciona sin conexión. Para imprimir o exportar, usar Imprimir del navegador con fondo activado.

El sistema visual es el mismo de la Evaluación II: azul navy, ámbar, la K de Kiran, Montserrat, IBM Plex Sans e IBM Plex Mono.

Las cifras corresponden al cierre del proyecto, el 9 de diciembre de 2026. El canal de asistencia quedó diferido para una segunda fase, con el techo vigente de US$ 20.700.
