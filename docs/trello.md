# Trello · Kiran

Para que Cursor (y yo) podamos crear listas y tarjetas en Trello.

## Conectar (una vez)

1. Abre este enlace de instalación oficial: [Instalar Trello MCP en Cursor](https://cursor.com/install-mcp?name=trello&config=eyJ0eXBlIjoiaHR0cCIsInVybCI6Imh0dHBzOi8vbWNwLnRyZWxsby5jb20vdjEifQ==)
2. En Cursor: **Settings → MCP** (o Customize → MCPs) y asegúrate de que **trello** esté encendido.
3. Pulsa **Connect / Log in** y autoriza con tu cuenta Trello.
4. En la pantalla de permisos elige el **workspace** del equipo y acepta **Read + Write**.
5. Abre un chat nuevo (o recarga la ventana) para que aparezcan las herramientas.

Sin ese login, no puedo tocar tableros.

## Qué vamos a usar

Un tablero **Kiran · GPY1102** con listas típicas de la Eva 1, por ejemplo:

- Backlog
- En curso
- En revisión
- Listo

## Si no aparece Trello en el chat

- Revisa que no hayas autorizado otro workspace
- Desconecta y vuelve a conectar con Read + Write
- Reinicia Cursor
